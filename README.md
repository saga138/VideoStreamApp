# VideoStreamApp

VideoStreamApp is a learning repository for building video streaming service UI patterns in SwiftUI and Jetpack Compose.

The project focuses on small, reviewable tasks that make it easier to compare platform-specific implementations while studying common streaming app screens such as home feeds, content detail pages, playback surfaces, search, and account areas.

## Learning Goals

- Practice SwiftUI and Jetpack Compose with similar screen requirements.
- Build UI patterns commonly found in long-form video streaming services.
- Keep each task small enough to review and understand before moving on.

## Current Status

Task 001 initializes the repository only. App scaffolding and UI work will be handled in later tasks.
